## 👋 Hola, soy Jairo Beneitez Baz

**Desarrollador de Aplicaciones Multiplataforma (DAM)** · **Técnico en Sistemas Microinformáticos y Redes (SMR)**

Estudio el segundo curso de DAM y vengo de sistemas: sé montar el equipo, configurar la red y desplegar encima la aplicación que escribo. Me interesa el software de escritorio y de móvil que se puede abrir, tocar y usar de verdad.

## Sobre mí

- 🎓 Cursando **2º de DAM** (Grado Superior en Desarrollo de Aplicaciones Multiplataforma), con el **Grado Medio en SMR** ya terminado.
- ☕ Escribo **Java** con JavaFX para escritorio y **Kotlin** para Android; uso **Python** para scripts y automatizar cosas.
- 🗄️ Trabajo con bases de datos relacionales (**MariaDB / MySQL**): del modelo al CRUD.
- 🧩 Me gusta la parte de interfaz: tablas, formularios y pantallas que se entienden a la primera.
- 🚧 Ahora mismo: publicando en GitHub los proyectos del ciclo y aprendiendo a montar apps Android completas.
